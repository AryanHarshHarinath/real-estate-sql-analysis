# real-estate-sql-analysis
This project analyzes real estate property data using SQL.

## Dataset
Two datasets were used:

1. real_estate_1
2. real_estate_2

The tables contain information about:

- property price
- location
- rent income
- vacancy rate
- walkability score
- crime rate
- property type

## Project Objectives

Solve 30 SQL business problems such as:

- identifying profitable properties
- ranking properties by price
- analyzing city-wise market trends
- calculating price per square foot
- Pareto analysis of property sales

## SQL Concepts Used

- Joins
- Subqueries
- Window Functions
- Ranking Functions
- Aggregate Functions
- Cumulative Calculations
- Percentile Analysis

## Example Insights

- Identified cities contributing highest to property sales
- Found top 10% premium properties
- Analyzed impact of public transport on property prices
- Calculated property price per square foot
